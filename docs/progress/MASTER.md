# NexusHub 当前状态（维护者）

## 版本与交付阶段

**1.2.15 核心实现已完成，正在收尾验收。** 本版增加 Bark 安全诊断、持久化有限重试和分段恢复，统一测试文案并退役旧配置导入。采用普通增量提交，API 协议保持 **2**。正式安装与远程服务仍待本轮发布更新。

## 当前实现

- 网络失败和结果未确认可有限重试；每分段最多 3 次，等待 15/60 秒并加入 ±20% 抖动，首次投递起最长 10 分钟，尊重 Retry-After。
- 复用 HTTP/2 连接池，禁止重定向，细分安全错误类别；已知永久 APNs 拒绝不因 HTTP 500 重试。日志不输出地址、Key、正文或原始异常。
- 加密队列保存不可变分段、确认进度、稳定匿名通知 ID 和租约；重启恢复未确认分段，成功分段不重发，结束清除正文。旧失败和未知结果不回放。
- 每次重试复核当前事件、身份、开关和目标；来源检查后再次读取配置，问题已回答、新回合替代、身份或目标改变时停止。正常追加不会单凭长度变化取消通知。
- 原事件呈现等待重试、重试中、已受理、失败、未确认和跳过；测试统一为“NexusHub 推送测试”并注明本机或腾讯云，作业等待真实终态。
- 删除旧配置导入实现与当前旧程序文案；历史防误报、退休入口拒绝及必要迁移保留。
