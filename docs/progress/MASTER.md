# NexusHub 当前状态（维护者）

## 当前版本

当前维护版本为 1.2.20。正式发布状态、说明与资产以 [GitHub Release](https://github.com/lich13/nexushub/releases) 为准，对应提交的完整回归结果见 [CI](https://github.com/lich13/nexushub/actions/workflows/ci.yml)。历史改动与交付记录由 Git 和 Release 保留。

## 当前改动

- Grok 分离活动显示与删除资格；有效登记确认无原生占用、记录完整且仅缺少结束事件的线程可进入删除预览。原生占用、身份无法确认、损坏和半行写入继续受保护，单项与批量共用判断。
- 隐藏扫描一次读取数据库元数据、全局索引和原生目录，建立文件引用映射；逐项流式验证身份、明确终态与内容指纹，删除执行仍重新核验当前来源。
- 分批扫描驻留内存，同源最多一个活动任务、进程最多两个上下文，共用 64MiB 预算；五分钟无请求取消释放，读取取消检查间隔最多 64KiB。
- 界面自动顺序取页、显示进度并支持停止，候选及结果每页最多 100 项；完整扫描后才启用清理确认，机器切换和离开页面隔离迟到响应。
- API 保持 2，复用 `cleanup.hiddenDryRun`，新增字段和能力均为可选；旧客户端保留完整响应，新客户端连接旧服务时回退单次扫描。

## 验证状态

核心实现通过 Grok 活动与删除资格、单项／批量一致性、隐藏清理事务与回滚、旧／新预览指纹对照、分页游标、来源隔离、取消、资源预算与同源／并发限制等针对性测试。WebUI 类型与相关单测、Rust 与 Tauri 编译、契约、格式、Clippy、安装脚本和隐私检查通过。完整回归与 Chromium／WebKit 检查沿用对应提交的三项 CI。

本机普通 dev 构建使用同一合成 fixture 生成器，分进程单次测量如下；峰值 RSS 包含该测试进程，不能与扫描上下文预算等同。

| 合成样本 | 原扫描耗时 | 新扫描耗时 | 新进程峰值 RSS |
|---|---:|---:|---:|
| 100 个隐藏线程 | 307ms | 33ms | 10.1MiB |
| 1,000 个隐藏线程 | 25.55s | 219ms | 16.5MiB |
| 5,000 个隐藏线程 | 未测 | 1.08s | 41.5MiB |
| 单个 100MiB 历史 | 未测 | 3.38s | 9.9MiB |

1,000 个样本的原进程峰值约 12.7MiB；共用上下文增加有界内存占用，减少逐候选重复全局扫描。100MiB 历史由 1,599 条合成 payload 记录组成，实际文件为 104,859,490 字节；内容指纹保持完整流式读取。以上不是 p95 或真实 App 交互结论，远程网络耗时未包含。

## 待用户验收

安装后在本机 Grok 对原先误保护的闲置线程打开删除预览，应允许预览；原生程序仍占用的会话应继续显示保护原因。在“更新与维护”扫描隐藏线程，检查进度、翻页、停止后禁用清理，以及重新扫描。实际删除、远程交互和日常使用体感由用户确认；自动化删除测试仅使用隔离 fixture，不以用户尚未验收阻塞交付。

## 保留边界

保留 Codex、Claude Code、Grok、Probe、设置、搜索、工具折叠、Plan、附件、路径、通知与子智能体阅读。增量缓存、自动历史分页、已回答问题展示和 100MiB／300MiB 颜色规则继续生效。Pi、Gotify、网页版和自动 Goal 恢复保持退役，有效迁移、兼容 tombstone、安全检查和回归测试继续保留。

资产范围仍为 macOS ARM64 DMG/checksum、updater archive/signature、latest.json 和 Linux x86_64 API tarball/checksum，共七项；updater 仅映射 darwin-aarch64。先升级 API，再安装正式 App，只做必要部署成功与启动检查。macOS 包无 Developer ID 签名或 Apple 公证，Minisign 不能替代系统代码签名。正式产物、会话、连接、凭据与共享缓存保留；本轮暂存清理量与性能收益分别报告。
