## 已完成实现

- Codex、Claude Code 和 Grok 共用紧凑阅读基线，标题栏、正文与活动摘要对齐；复制动作不占正文行高，用户气泡与原有折叠规则保留。
- 子智能体创建调用与结果按原生身份、精确任务路径及父子关系配对，状态读取其自身回合。关联有歧义时保持不可用，不按名称猜测。
- 右侧详情独立分页与滚动，复用消息、工具、Plan、附件、路径、记忆过滤及 AGENTS.md 折叠。关闭后恢复父线程位置与焦点，机器切换关闭面板并隔离请求。
- 共享只读契约贯通 core、Linux API、Tauri 和 WebUI；子线程及附件绑定可见主线程，验证父链、循环、深度、文件身份与指纹。
- Hook 测试使用本次 Cargo 构建的 CLI，保留真实子进程、确认等待和通知去重断言。
- Keychain 读写共用后台串行通道，读取限时 15 秒；超时和取消不释放仍在执行的原生操作所持许可。保存与移除连接保持完整事务，提交或回滚后才允许切换，能力验证前后再次检查连接身份。
