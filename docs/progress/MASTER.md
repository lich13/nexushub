# NexusHub 当前状态（维护者）

## 版本与交付阶段

**1.2.16 核心实现完成，正在进行发布验收。** 自动加载历史与线程大小已接入本机和远程共用链路；尚未发布或安装本版。采用普通增量提交，API 协议保持 **2**。上一正式版本为 [v1.2.15](https://github.com/lich13/nexushub/releases/tag/v1.2.15)。

## 当前实现

- Codex 主线程、Claude 和 Codex 子智能体向上滚动到顶部附近自动逐页读取；首次打开定位最新内容，搜索与滚动协调相同游标，失败显示就地重试。
- 以可见消息及像素偏移保持视口，处理加载期间继续滚动、轮询追加及工具展开；轮询保留已有历史与最早游标。切换机器、线程或子智能体后旧响应失效。
- Codex 统计已验证的 rollout；Claude 统计主 JSONL 及确认归属的专属目录；Grok 统计会话目录。只读元数据、不跟随符号链接、不计工作目录和共享存储。
- 后台目录扫描、队列与缓存有界，最长 30 秒刷新；普通追加保留可用缓存，截断或身份改变立即失效。部分结果与未知状态明确区分。
- 三种列表状态行右侧显示 K／M／G，绿色／琥珀色／红色对应单位；支持精确字节及口径提示，不增加卡片高度。DTO 新字段可选，旧服务显示 —。

## 已验证

- 受管完整 Rust workspace 测试通过，存储统计集成测试 12 项；后端 Clippy 和 fmt 通过，包含追加、截断、身份变化、符号链接、专属目录和扫描边界。
- 受管前端类型检查、构建及 452 项单元测试通过；后续加强历史窗口身份覆盖，针对性历史窗口测试 13 项通过。包含首次定位、连续上滚、重复请求、错误重试、轮询与分页游标协调。
- 工作树隐私及 diff 检查通过。浏览器用例正在更新，完整 Chromium/WebKit、Tauri 以及最终冻结版本门禁仍待对应提交 CI。
