## 本版调整

- 线程右键、省略号和键盘操作共用菜单；右键其他线程保持当前详情，双击改名与批量入口保留。
- Codex 普通及归档线程支持预览后永久删除，复核明确终态、身份、数据库关联、索引、共享引用与文件指纹。
- 隐藏清理只处理本次预览候选；受保护项逐项跳过，单项失败记录后继续，公共存储或数据库故障回滚整批。
- Grok、Codex、Claude 列表卡片统一宽度。窗口隐藏创建后一次适配当前工作区，重开和机器切换只显示、恢复和聚焦。
- Pi 活动契约、界面、读取器与通知集成退役；旧请求返回不可用。升级精确清除 NexusHub 自有的 Pi 队列和配置，不操作原生 Pi 数据。

## 已验证

### 门禁与发布资产

WebUI frozen install、类型检查、268 项单元测试、生产构建及 Chromium/WebKit，Rust/Tauri fmt、test、Clippy，以及契约、迁移、安装和隐私门禁通过。

七项资产的 SHA-256 均与 GitHub digest 相符，两份校验文件验证通过，macOS updater 的 Minisign 签名验证通过。`latest.json` 版本为 1.2.8，仅包含 `darwin-aarch64`；DMG、updater App 和内嵌 helper 的版本相符。Linux 包只包含 API 服务及部署工具、文档。

### 远程 API

正式服务已升级，运行二进制与正式包一致；认证 HTTPS 能力接口返回协议 2。未认证业务请求返回 401，旧 Pi 请求及旧页面返回 404，缺少候选列表的旧隐藏清理请求返回 400。API Key、业务配置及 systemd 隔离参数保留，Pi 写入白名单已移除。

在同一服务器用正式二进制和仓库外隔离数据验证：普通与归档线程删除共 2 项成功；隐藏清理删除 1 项、跳过 2 项、失败 0 项；预览后新增的线程未被纳入，保留线程和工作目录未变。隔离服务已停止。这是隔离接口验收，不代替正式 App 的管理流程验收。

### 正式 macOS App

正式原包已安装并启动。冷启动标准窗口填满当前屏幕工作区，没有切入独立全屏 Space；三个 Provider 导航正确且无 Pi，Grok 卡片等宽。右键未选中项立即打开菜单而不改变详情；Escape、外部点击、Shift+F10 和省略号入口通过。本机 NexusHub 数据库完整性为 ok，Pi 提供方、流和投递记录已清除。

切换远程时，macOS 钥匙串要求用户授权新版 App 读取现有 API Key；系统提示仍在等待用户处理。当前未将等待中的能力查询算作远程界面验收通过，也未修改 Keychain 权限或重建连接。

## 待完成与已知边界

- 用户完成系统钥匙串授权后，继续验证正式 App 的远程读取、对应更新面板及切回本机。
- 正式 App 的专用会话永久删除、隐藏清理混合批次，以及手动缩放后的重开/最小化恢复验收仍待完成；不在真实用户会话上做破坏性测试。
- 待上述验收通过后恢复正式配置、核对连接与原生数据、检查关闭 App 后 monitor 持续运行且无监听端口，再清理剩余任务产物。
- 多显示器及不同系统缩放比例尚未完成物理设备验收。
- macOS 包未配置 Developer ID 签名或 Apple 公证；`codesign` 资源封口校验报告缺失。Minisign 更新签名已通过，正式原包可以启动；两种签名的验收结果分别记录。
