## 已完成实现

- 活动、列表和详情共用任务名解析；创建任务名优先于线程标题、角色或随机昵称。
- 详情按原生 ID 统计直属子智能体，集合不受消息分页影响。当前状态来自子线程自身回合，父线程未追加时仍刷新；嵌套详情只统计自身直属下级。
- 汇总打开右侧列表，可进入详情并返回；父线程保留阅读位置、搜索定位和折叠。机器切换关闭面板并隔离请求，主线程列表不增加计数。

- 完整内部页面包装从显示、复制、Plan 导出及搜索中排除；代码、引用及未确认结构保留，纯包装不生成空气泡和时间线标记。

## 保留边界

子智能体详情只读，不提供发送、停止、接管、审批、分叉或管理动作，不修改原生会话，不新增数据库表或 RPC。关联不明时保留未知或不可用状态，不按名称猜测，不把缺失数据当作完成。

发布资产仍为 macOS ARM64 DMG/checksum、updater archive/signature、`latest.json`，以及 Linux x86_64 API tarball/checksum，共七项。Linux 网页和桌面发行已退役。

macOS 包没有 Developer ID 签名或 Apple 公证。1.2.12 的普通及严格资源封装校验仍存在此前版本已有的资源缺失问题，未宣称系统代码签名通过；有效的 Minisign 更新签名不能替代该校验。GitHub 可能保留不可达对象，可达历史扫描不表示平台缓存已全部擦除。私人路径、域名、身份、凭据与真实会话正文不进入文档、测试或发布资产。
