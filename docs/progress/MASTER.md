# NexusHub 当前状态（维护者）

## 版本与交付阶段

**1.2.9 收尾验证中，尚未正式发布。** 当前改动基于 1.2.8，采用正常增量提交。

本版统一 Codex、Claude Code、Grok 的紧凑阅读布局，新增 Codex 子智能体只读详情，修复 Hook 集成测试二进制路径依赖。远程 API 协议保持 **2**，新增 `thread_subagents` 能力。

## 已完成实现

- 标题栏、正文与活动摘要收紧并对齐；移除重复 Provider 标签，复制按钮使用不占正文行高的侧边动作位。
- 创建调用和结果配对子智能体，支持精确任务路径、嵌套关系与自身回合状态；异常关联不猜测。
- 右侧详情独立分页和滚动，复用消息、工具、Plan、附件、路径、记忆过滤及 AGENTS.md 折叠；关闭后恢复父线程位置与焦点。
- 共享只读契约贯通 core、Linux API、Tauri 和 WebUI；子线程附件绑定原主线程并验证来源。
- Hook 测试只使用本次 Cargo 构建的二进制，保留真实 CLI、等待及去重断言。

## 保留边界

子智能体详情只读，无发送、停止、接管、审批、分叉或管理动作；不修改原生会话，不新增数据库表。主线程列表与通知边界、现有线程管理保护、API Key、Keychain、Bark 和机器隔离保持原规则。

发布包含七项资产：macOS ARM64 DMG/checksum、updater archive/signature、`latest.json`，Linux x86_64 API tarball/checksum。Linux 网页和桌面发行均已退役。

macOS 发行包尚无 Developer ID 签名或 Apple 公证；Minisign 更新签名与系统代码签名分别验收。GitHub 可能保留不可达对象，可达历史扫描不代表平台缓存已全部擦除。真实路径、域名、身份、凭据与会话内容始终不进入文档、测试或发布资产。
