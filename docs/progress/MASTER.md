## 当前实现

- Codex 主线程、Claude 和 Codex 子智能体向上滚动到顶部附近自动逐页读取；首次打开定位最新内容，搜索与滚动协调相同游标，失败显示就地重试。
- 以可见消息及像素偏移保持视口，处理加载期间继续滚动、轮询追加及工具展开；轮询保留已有历史与最早游标。切换机器、线程或子智能体后旧响应失效。
- Codex 统计已验证的 rollout；Claude 统计主 JSONL 及确认归属的专属目录；Grok 统计会话目录。只读元数据、不跟随符号链接、不计工作目录和共享存储。
- 后台目录扫描、队列与缓存有界，最长 30 秒刷新；普通追加保留可用缓存，截断或身份改变立即失效。部分结果与未知状态明确区分。
- 三种列表状态行右侧显示 K／M／G，绿色／琥珀色／红色对应单位；支持精确字节及口径提示，不增加卡片高度。DTO 新字段可选，旧服务显示 —。

## 清理

已删除本轮下载、解包、恢复副本、旧 App 备份、临时格式检查文件与受保护测试控制文件；按互不重叠路径和文件身份去重，逻辑数据合计 **159,190,735 字节（151.8 MiB）**，删除前文件已分配块合计 **161,112,064 字节（153.6 MiB）**。占用按已删除文件计量，不等同于同期系统整体可用空间变化。

## 保留边界

Codex、Claude Code、Grok 的事件识别、会话、搜索、用户指令时间线、工具折叠、Plan、附件、路径和子智能体详情继续使用。Pi、Gotify 与网页版保持退役，保留现有用户会话、连接、API Key、Bark 凭据与通知状态。

发布资产仍为 macOS ARM64 DMG/checksum、updater archive/signature、latest.json，以及 Linux x86_64 API tarball/checksum，共七项；updater 仅映射 darwin-aarch64。macOS 包没有 Developer ID 签名或 Apple 公证，Minisign 不能替代系统代码签名。Bark 网络结果未知时有限重试可能重复提醒；HTTP 成功只记为服务端受理。
