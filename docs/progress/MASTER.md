## 已完成实现

- 识别原生 `SubAgentActivity` 的开始、完成、中断及交互事件，保留历史时点；同次创建调用/结果与原生活动配对去重，续接的新开始独立保留。
- 活动、列表和详情共用任务名解析；不再由线程标题、角色或随机昵称覆盖创建任务名。
- 详情显示直属子智能体集合及状态数量，分页前按原生 ID 去重。父线程未追加也重新读取子线程状态；嵌套详情只统计自身直属下级。
- 汇总可打开右侧列表，再进入详情并返回；父线程保留挂载、阅读位置、搜索定位和折叠。机器切换隔离请求并关闭面板，主线程列表不增加计数。
- 历史开始文案与当前状态分开；最新详情刷新保留原生顺序，早期已加载活动同步更新但不重置锚点。
- 完整内部页面包装默认隐藏，显示、复制、Plan 导出及搜索同步过滤；代码、引用及未确认结构保留，纯包装不生成空气泡和时间线标记。

## 保留边界

子智能体详情只读，无发送、停止、接管、审批、分叉或管理动作；不修改原生会话，不新增数据库表或 RPC。关系有歧义、记录缺失或读取不完整时明确提示，不按名称猜测或把未知当作完成。

发布仍为七项资产：macOS ARM64 DMG/checksum、updater archive/signature、`latest.json`，Linux x86_64 API tarball/checksum。Linux 网页和桌面发行已退役。

macOS 包为 ad-hoc 签名、无 Developer ID；Minisign 更新签名与系统代码签名分别核验，不能互相替代。GitHub 可能保留不可达对象，可达历史扫描不代表平台缓存已全部擦除。私人路径、域名、身份、凭据与会话内容不进入文档、测试或发布资产。
