# NexusHub 当前状态（维护者）

## 当前版本

当前维护版本为 1.2.21。正式发布状态、说明与七项资产以 [GitHub Release](https://github.com/lich13/nexushub/releases) 为准，对应提交的完整回归结果见 [CI](https://github.com/lich13/nexushub/actions/workflows/ci.yml)。历史改动与测量记录由 Git 和 Release 保留。

## 当前改动

- 共享用户消息投影拆分真实正文、附件和自动上下文；完整环境、运行信息、AGENTS.md 与新旧附件说明合并为一个默认收起的“上下文”入口，展开时才挂载正文。
- 按附件、上下文、真实请求排列，保留换行和原生附件身份；纯上下文不生成空气泡或时间线刻度。代码、引用、普通 XML 和不完整包装保留原文，原生问答继续专用展示。
- 搜索与摘要只取实际用户内容；搜索另保留问题与回答、附件名和 AGENTS.md 指令，排除自动字段及结构化 memory/Page 元数据。
- 三种 Provider 和 Codex 子线程共用完整用户消息时间线。索引独立于正文分页与折叠，按稳定身份读取定位窗口，支持较早/较新分页和返回最新；静态历史不随轮询重复读取。
- 左侧刻度与单个悬停预览缩窄，大量刻度保持有界挂载及键盘访问。Grok 冷读改为完整流式读取，修复超过 64MiB 时丢失最早记录。
- API 协议保持 2，新增详情字段可选，旧服务保留原始包装和逐页加载回退；不新增 RPC、数据库表或客户端路径权限，不改写原生会话。
- 接续已批准的工具链升级：Node 24.21.0、pnpm 12.11.2、TypeScript 7.0.2、Vite 8.3.4、Vitest 5.0.4 和现有 Rust stable；沿用锁文件及增量缓存。

## 验证状态

本机上下文针对性测试覆盖两类原生附件包装、相邻及混合上下文、AGENTS.md、失效附件、代码/引用/半截结构、原生问答、搜索和旧服务兼容。新增 Rust 时间线测试 7 项，覆盖三个 Provider、折叠历史、稳定游标、追加、目标消失和超过 65MiB 的 Grok 合成记录；另通过相关缓存、核心契约和 webd 详情/分页测试。

新增前端导航测试 14 项及相关回归 113 项通过，覆盖跨机器/线程的迟到响应、双向窗口合并、定向刷新、5000 条索引下的有界挂载、键盘访问和锚点更新。WebUI 构建、Clippy、Tauri 编译、格式与 diff 检查通过；核心交接前隐私扫描检查 2320 项，零失败。测试只使用脱敏 fixture，不代表真实 App 验收。

完整回归、跨平台构建及 Chromium/WebKit 的现有 100ms 交互预算交由对应提交的三项 CI；此处不以旧版本的性能数字代表本版本。真实界面延迟、滚动体感以及子面板下钻返回的专门交互尚未验收。

## 待用户验收

安装后打开包含环境、AGENTS.md、图片及新旧附件包装的主线程和子线程。默认应只显示附件、真实请求与一行“上下文”；展开可读原文，刷新与分页保留手动选择。搜索真实请求、问题回答及 AGENTS.md 应能定位，搜索自动环境字段不应命中消息。

在长线程悬停并点击最早的时间线刻度，检查窄预览、较早/较新分页、返回最新，以及滚动或 Home/End 遍历全部用户记录。测试加载期间继续滚动、工具展开、切换机器和子面板下钻返回。视觉、日常体感和实际管理操作由用户确认，不以尚未验收阻塞助手交付。

## 保留边界

保留 Codex、Claude Code、Grok、Probe、设置、搜索、工具折叠、Plan、附件、路径、通知与子智能体阅读。Grok 删除资格、隐藏扫描进度/停止、管理预览指纹、自动历史分页及 100MiB/300MiB 颜色规则继续生效。Pi、Gotify、网页版和自动 Goal 恢复保持退役，有效迁移、兼容 tombstone、安全检查和回归测试继续保留。

资产范围仍为 macOS ARM64 DMG/checksum、updater archive/signature、latest.json 和 Linux x86_64 API tarball/checksum，共七项；updater 仅映射 darwin-aarch64。先升级 API，再安装正式 App，只做必要部署成功与启动检查。macOS 包无 Developer ID 签名或 Apple 公证，Minisign 不能替代系统代码签名。正式产物、会话、连接、凭据与共享缓存保留；暂存清理量与性能收益分别报告。
